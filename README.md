# 업무 현황판

최현우님의 업무·생활 현황판을 아이폰 홈 화면(PWA)에서 앱처럼 쓰기 위한 정적 사이트입니다.

## 쓰는 법

1. 아이폰 Safari에서 https://jackhyunwoo.github.io 접속
2. 공유 → **홈 화면에 추가** → 이름 "업무 현황판"
3. 이후 홈 화면 아이콘으로 열면 주소창 없는 앱 화면으로 뜹니다 (한 번 연 뒤에는 오프라인에서도 열립니다).

## 데이터 고치기 (index.html은 건드릴 필요 없음)

모든 내용은 `data.json` 하나에 있습니다. 파일만 고쳐서 올리면 화면이 그대로 바뀝니다.

- `meta.updatedLabel` — 화면 위에 표시되는 "업데이트" 시각
- `trip` — 출장 제목, 출국일, 귀국일, 지난 박수/전체 박수 (D-Day와 체류 진행률이 여기서 계산됩니다)
- `tracks` — 진행률 지표(퍼센트 바). `now` / `goal` 을 바꾸면 퍼센트가 바뀝니다
- `items` — 항목 카드. `cat` 은 `progress` | `decision` | `done` | `upcoming`
  - `progress: { now, goal, unit, label }` 을 넣으면 카드에 진행률 바가 생깁니다
- `hotel` — 호텔·항공 카드와 힐튼 마일스톤
- `shopping` — 블프 딜·동선·할인코드
- `accounts` — 연결된 서비스 목록(아이디·비밀번호는 절대 넣지 않습니다)

### 고친 뒤 올리기

```bash
git add data.json && git commit -m "현황 업데이트" && git push
```

GitHub Pages가 1분 안에 다시 올립니다. 앱에서 ⟳ 버튼을 누르면 즉시 최신 `data.json`을 다시 읽습니다.

## 체크·메모

- 카드 오른쪽 체크박스(확인함)와 맨 아래 **내 메모장** 내용은 `localStorage`에 저장됩니다. 기기(브라우저)마다 따로 저장되고, 사이트에는 올라가지 않습니다.
- 맨 위의 **전체 작업 완료율**은 완료 항목 + 확인함 표시한 항목의 비율입니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 전체(스타일·스크립트 포함). `data.json`을 읽어 그리고, 실패하면 내장 사본으로 표시 |
| `data.json` | 현황 데이터 (여기만 고치면 됨) |
| `manifest.json` | PWA 설정(앱 이름·아이콘·standalone) |
| `sw.js` | 오프라인 캐시 |
| `icons/` | 홈 화면 아이콘 (180·192·512·maskable) |

## 공개 주의

이 저장소는 공개(public)이고 GitHub Pages는 누구나 볼 수 있습니다. 전화번호, 이메일, 생년월일, 상세 주소, 예약번호(PNR), 회원번호, 비밀번호는 넣지 않습니다. `data.json`을 고칠 때도 같은 규칙을 지켜 주세요.
